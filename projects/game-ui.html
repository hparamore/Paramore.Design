Game UI

Role Solo Designer
Discipline UI Design · Visual Systems
Tools Figma
Format UI Kits · HUD · Menus

UI is loudest in games.

Game UI lives in the hardest spot in design, it has to communicate fast, sit inside a living world, and never break the spell. These are personal studies of three very different games, rebuilt in Figma to understand how each one solves that problem.

Each kit is a complete component library, type, color, iconography, HUD states, menu flows, published on my Figma community profile for anyone to fork or learn from.

Kit 01 // Nintendo Switch

Zelda Breath of the Wild

A study of one of the most quietly confident UI systems ever shipped, restrained color, generous negative space, and iconography that feels carved rather than drawn. The kit covers the pause menu, inventory, map, runes, and shrine UI.

Kit 02 // PC

Satisfactory

A factory-builder lives or dies by its UI, players spend hours inside menus, build trees, and production graphs. This kit reconstructs Satisfactory's industrial, schematic-style interface: build menus, the MAM tree, AWESOME shop, and HUD readouts.

Kit 03 // Mobile

Raid Rush

A mobile RPG UI kit, character screens, gear loadouts, raid queues, and the relentless economy of menus that mobile games run on. Built as a complete component set so the visual language stays consistent across every surface.

Want the files?

Every kit is published on my Figma community profile, free to duplicate, fork, or rip apart for your own work.
