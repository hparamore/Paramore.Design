Drop Paramore Real Estate photos in this folder.

Any .png / .jpg / .jpeg / .webp file here is picked up automatically by
src/pages/projects/paramore-real-estate.astro at build time and rendered in the
page's gallery grid, sorted by filename. No code change needed.

Prefix with numbers to control order, e.g. 01-signs-at-dusk.jpg.
The filename (minus the number prefix) becomes the alt text, so name them
descriptively.
